# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, be professional, focus on the work.

## Unacceptable behavior

- Harassment, insults, or personal attacks
- Trolling or deliberately disruptive conduct
- Publishing others' private information without permission
- Anything that would be obviously unwelcome in a professional setting

## Scope

Applies to all project spaces: issues, pull requests, discussions, commit messages, and any community channels maintained by the project.

## Enforcement

Report violations to `conduct@webrenew.io`. Maintainers will review and respond within a reasonable timeframe. Possible responses range from a private warning to a permanent ban. Maintainer decisions are final.
