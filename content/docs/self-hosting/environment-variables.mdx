import { Callout } from 'fumadocs-ui/components/callout';

`.env.example` in the repository is the starting template. Copy it to
`.env.local` for local development, or to `.env` for Docker.

<Callout type="warn" title="NEXT_PUBLIC_* values are build-time">
  Next.js compiles every `NEXT_PUBLIC_*` value into the client bundle when it
  builds. Changing one at runtime has no effect. Rebuild after each change. With
  Docker, pass them as `--build-arg`.
</Callout>

Trigger.dev tasks need the same **server** variables as the app. See
[Background jobs](/self-hosting/background-jobs#3-give-the-tasks-their-environment).

## Required

| Variable | Notes |
| --- | --- |
| `MOGPLEX_DATA_BACKEND` | `neon`. |
| `NEXT_PUBLIC_MOGPLEX_DATA_BACKEND` | `neon`. Must match `MOGPLEX_DATA_BACKEND`. Build-time. |
| `APP_URL` or `NEXT_PUBLIC_APP_URL` | Public URL of the deployment, such as `https://mogplex.example.com`. `APP_URL` wins and is read at runtime, so one image serves any domain. |
| `DATABASE_URL` | Owner connection. Migrations use it, and the app falls back to it. |
| `DATABASE_URL_UNPOOLED` | Direct connection, for `pg LISTEN`. |
| `BETTER_AUTH_SECRET` | `openssl rand -base64 32`. |
| `CRON_SECRET` | Bearer token for `/api/cron/*` and machine-only routes. |
| `INTERNAL_API_SECRET` | Server-to-server sandbox actions. |
| `CONNECTIONS_ENCRYPTION_KEY` | 32-byte hex key (`openssl rand -hex 32`) that encrypts saved connection credentials. Do not rotate without a plan: see [Operations](/self-hosting/operations#secrets). |
| `EMAIL_UNSUBSCRIBE_SECRET` | Signs unsubscribe links. The app throws in production without it. |
| One sign-in provider | `AUTH_GITHUB_*`, `AUTH_GOOGLE_*`, `AUTH_MICROSOFT_*`, or Resend for email and password. |

`pnpm setup:doctor` checks these and the optional services below.

## Auth and email

| Variable | Notes |
| --- | --- |
| `BETTER_AUTH_URL` | Defaults to `NEXT_PUBLIC_APP_URL`. |
| `BETTER_AUTH_API_KEY` | Optional. Connects the better-auth.com dashboard. |
| `AUTH_GITHUB_CLIENT_ID`, `AUTH_GITHUB_CLIENT_SECRET` | GitHub sign-in. Callback: `/api/auth/callback/github`. |
| `AUTH_GOOGLE_CLIENT_ID`, `AUTH_GOOGLE_CLIENT_SECRET` | Google sign-in. Callback: `/api/auth/callback/google`. |
| `AUTH_MICROSOFT_CLIENT_ID`, `AUTH_MICROSOFT_CLIENT_SECRET` | Microsoft sign-in. Callback: `/api/auth/callback/microsoft`. |
| `AUTH_MICROSOFT_TENANT_ID` | Default `common` (any Microsoft account). |
| `RESEND_API_KEY` | Required for email and password sign-up (verification email). |
| `WAITLIST_FROM_EMAIL` | Default sender, on a domain verified in Resend. |
| `AUTH_FROM_EMAIL`, `BILLING_FROM_EMAIL` | Optional senders. Fall back to `WAITLIST_FROM_EMAIL`. |

## GitHub

| Variable | Notes |
| --- | --- |
| `GITHUB_APP_ID` | GitHub App ID. |
| `GITHUB_APP_NAME` | GitHub App slug, as in `github.com/apps/<slug>`. |
| `GITHUB_APP_PRIVATE_KEY` | PEM. Write newlines as `\n` in single-line env files. |
| `GITHUB_WEBHOOK_SECRET` | Must match the App's webhook secret. |
| `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` | Classic GitHub OAuth app for repository listing and reauthorization. The GitHub App's own client credentials do not work here. |
| `MOGPLEX_SETUP_ENABLED` | `1` enables `/admin/setup/github` in production while the GitHub App is unconfigured. Remove it after setup. |

See [GitHub App](/self-hosting/github-app).

## Models and agent features

| Variable | Notes |
| --- | --- |
| `AI_GATEWAY_API_KEY` | Platform model access through Vercel AI Gateway. |
| `OPENROUTER_API_KEY` | Optional. Model catalog sync. |
| `OPENAI_API_KEY` | Optional. Memory embeddings. Without it, memory search uses plain text matching. |
| `EXA_API_KEY` | Optional. Agent web search and page extraction. Server-side only. |
| `EXA_RESEARCH_SECRET` | Optional. Lets Trigger.dev workers use web search through the app. |
| `AUTOMATION_GATEWAY_CACHING` | Optional. `off` turns off prompt caching for automation jobs. |
| `AUTOMATION_GATEWAY_FALLBACK_MODELS` | Optional. Comma-separated fallback models for automation jobs. |
| `DECISION_MODES`, `DECISIONS_DISABLED` | Optional. Overrides for the decision layer. |
| `MOGPLEX_HARNESS_ACP` | Optional. `off` runs Codex through its CLI instead of the Agent Client Protocol. |
| `MOGPLEX_OPENAI_COMPATIBLE_BASE_URL` | Optional. Your OpenAI-compatible endpoint, such as LiteLLM, vLLM, or Ollama. |
| `MOGPLEX_OPENAI_COMPATIBLE_API_KEY` | Optional. Sent only to that endpoint. |
| `MOGPLEX_OPENAI_COMPATIBLE_MODELS` | Comma-separated model IDs, with an optional `id=Label`. |

## User access

| Variable | Notes |
| --- | --- |
| `MOGPLEX_SELF_HOSTED` | `1` grants platform AI and sandbox access to every signed-in user and hides billing. Ignored while `STRIPE_SECRET_KEY` is set. |
| `MOGPLEX_SELF_HOSTED_ALLOWED_EMAIL_DOMAINS` | Optional. Limits self-host mode to these email domains. |
| `PLATFORM_ACCESS_EMAILS` | Comma-separated emails with platform AI and sandbox access. |
| `PLATFORM_ACCESS_EMAIL_DOMAINS` | Comma-separated domains, such as `example.com`. |
| `PLATFORM_ACCESS_USER_IDS` | Comma-separated Mogplex user IDs. |

See [Give users access](/self-hosting/sandboxes-and-models#give-users-access).

## Billing (optional)

Leave these unset to run without billing. Then grant access with the
[allowlists](#user-access).

| Variable | Notes |
| --- | --- |
| `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` | Your Stripe account. Webhook: `/api/webhooks/stripe`. |
| `CAPACITY_BILLING_OPERATIONS_ENABLED` | Default `false`. Turns on capacity billing operations. |
| `CAPACITY_BILLING_LIVE_WRITES_ENABLED` | Default `false`. Required with a live Stripe key. |
| `CAPACITY_BILLING_PILOT_ACCOUNT_IDS` | Comma-separated billing account IDs for the reserved-concurrency pilot. |

## Docker Compose

| Variable | Notes |
| --- | --- |
| `COMPOSE_PROFILES` | `postgres` starts the bundled Postgres; `.env.example` sets it. Remove it when `DATABASE_URL` points at an external database. |
| `MOGPLEX_VERSION` | Image tag to run, such as `v0.2.0`. Default `latest`. |
| `MOGPLEX_IMAGE` | Image repository. Default `ghcr.io/mogplex/mogplex`; set it to use a mirror. |
| `MOGPLEX_PORT` | Host port for the app. Default `3000`. |
| `POSTGRES_PASSWORD` | Password for the bundled Postgres. Ignored when you set `DATABASE_URL`. |
| `CRON_TARGET_URL` | Base URL the cron scheduler calls. Compose sets it to the `app` service. |

## Other

| Variable | Notes |
| --- | --- |
| `NEXT_PUBLIC_C15T_URL` | Optional. Hosted cookie-consent backend. If unset, consent is stored only in the browser. Build-time. |
| `NEXT_PUBLIC_VERCEL_APP_CLIENT_ID`, `VERCEL_APP_CLIENT_SECRET` | Optional. **Sign in with Vercel** (identity only). Callback: `/api/auth/vercel/callback`. Build-time client ID. |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` | Legacy Supabase deployments only. Leave them empty for Neon. |
