conversations, your tools, and your models. Start with GitHub. Add the others
when a workflow needs them.

## Integration order

1. Connect GitHub and install the Mogplex GitHub App. Confirm coverage in
   [Installations](/web/installations) before you debug webhook routing.
2. Add Slack if your team requests work in chat.
3. Add tool connections for the services agents must read or change.
4. Add provider keys only if you want usage billed to your own provider
   account.

Running Mogplex on your own infrastructure? Each integration needs your own
app or credentials. See [Self-hosting](/self-hosting).
